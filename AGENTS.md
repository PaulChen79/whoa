# whoa

Stop-loss for coding agents — catches loops, goal drift, and test-weakening in Claude Code and Codex.

## Language

Everything public is written in English: source, comments, commit messages, `CONTEXT.md`, ADRs, README, and issues. Chinese appears only in gitignored local working documents such as `docs/SPEC.md`.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues at `PaulChen79/whoa`, operated via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
